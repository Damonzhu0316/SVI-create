# 街景智析｜基于深度学习的街景多目标检测与可视化分析系统

街景图像检测、可视化校正和训练数据整理前端。应用使用 Transformers.js / ONNX Runtime Web 在浏览器本机执行推理。

## 启动

在本目录启动静态文件服务器后访问本地地址：

```bash
python3 -m http.server 8000
```

打开 `http://localhost:8000`。首次使用需联网加载 JavaScript 运行时和公开模型权重；单图、批量图片和自定义模型文件均由浏览器本地读取。

## 功能

- 工程管理：可新建、打开、切换和导入/导出工程包；街景采样点、来源坐标、图片、检测标注、批量状态和复核结果保存到本机工程目录。批量任务可从另一工程或本地文件夹导入图片；图片原文件不再写入浏览器 IndexedDB。 启动后先填写称呼并选择模式：浏览器简易模式提供单图检测及其配套的模型、分析、记录和帮助页面；创建工程模式先填写工程名称、存储目录和说明，创建或打开工程后进入街景采集、批量任务、训练数据、任务记录和数据洞察等工程功能，不提供单图检测。工程管理入口集中在“批量任务”页面。

- 按使用模式呈现工作区：简易模式提供单图检测与配套页面，工程模式提供采集、批量检测、训练数据、任务记录和数据洞察；界面采用蓝白银主色，并以蓝、白、银、黑的层次和科研网格纹理区分重点
- 功能介绍页说明从区域采集到检测、结果确认和数据导出的完整流程；批量任务支持按文件名、待处理/待确认/已确认状态筛选，支持失败重试和清空队列；工程内的图片、采集参数、标注、历史和确认状态自动保存在电脑工程目录，可下次打开工程恢复
- 单图及多文件上传、拖放、队列进度与失败状态
- 街景采集页支持省/市/区县/街道乡镇级联定位、手动坐标、经纬度范围、地图矩形框选和地点查询（可直接输入地名或区域描述）；可选择路网并按设定间距生成采样点，预览所选点的街景缩略图，再采集并加入批量检测队列
- Transformers.js 目标检测模型：YOLOS-Tiny/Small/Base、DETR ResNet-50/101、YOLOv9-C
- 导入本地 YOLOv8 Detect 原始输出格式 ONNX，并按类别名与输入尺寸配置运行 WASM 推理
- 检测框、类别、置信度与画面位置可视化；单图工作台支持拖动、缩放、改类、删除、补画和撤销重做；批量检测完成后可逐张翻看带检测框图片，并用“一键确认模型结果”统一确认已完成图片
- 批量结果 ZIP：原图、叠加检测框的可视化图片、JSON 标注结果
- YOLO 数据集 ZIP：images/train、images/val、labels/train、labels/val 和 data.yaml；支持配置验证集比例
- 训练参数 YAML 导出与类别统计；训练数据由已确认图片生成，街景采集数据优先按道路分组划分
- 训练完成后在本机将 best.pt 转为浏览器可加载的 ONNX，类别名与输入尺寸自动带入当前会话
- 目标类别统计、置信度分布、空间热区和检测目标排行

## 街景数据采集（免 API Key）

运行 acquisition_service/start_acquisition_service.command 后，先在页面顶部新建或打开工程；工程默认保存在用户目录下“街景智析/工程”。采集到的图片、坐标和检测结果保存在工程文件夹，工程可导出为 ZIP 或下次重新打开。在“街景采集”页面可从省/直辖市、市/地区、区县、街道/乡镇逐级选择定位，也可输入坐标、填写范围、在地图框选矩形，或用地点查询（可直接输入地名或描述区域）。选择道路后按采样间距生成采样点；数量上限留空时不再额外抽稀，服务端单次最多生成 5000 点。地图框选和范围采样单次不超过 20 km × 20 km、面积不超过 400 km²。采集前可勾选采样点并点击“预览所选街景”，最多一次预览 25 张；预览过的图片会在正式采集时复用。道路选择优先读取项目内“2025年全国道路铁路数据/全国道路数据.shp”本地路网，不依赖 Overpass 在线道路接口。 该约 7.4 GB 的外部数据集不包含在 GitHub 代码仓库中；需要本地道路选择时，请自行准备并放到上述路径。行政区划数据与 Nominatim 定位、地图瓦片需要网络。正式采集时，本机服务调用 HNU_StreetView_Front_v6/scripts/front_view.py 中的百度 pano 元数据与 pr3d 影像流程，图片加入当前工程的批量队列，并保存在本机工程目录。批量检测完成后可逐张查看带检测框的图片，再点击“一键确认模型结果”；确认后的图片可用于 YOLO 训练数据导出。

地点查询入口默认用本机规则处理地名。若要使用你的中转大模型，在 `acquisition_service/ai_config.local.env` 中填写 `AI_BASE_URL`（兼容 OpenAI Chat Completions 的服务地址）、`AI_MODEL`（模型名）和 `AI_API_KEY`（中转密钥）；密钥只由本机 Python 服务读取，不会发到浏览器。配置后重启采集服务生效。地点查询先经过本地输入校验；AI 只负责从地点描述中提取可搜索地点名；提交内容会发送给你配置的 AI 中转和 OpenStreetMap Nominatim。每次手动提交只查询一次，Nominatim 请求限速并在本机内存缓存。OpenStreetMap 要求署名，公开服务最多每秒 1 次请求，请勿输入隐私/机密信息。详见 [Nominatim 使用政策](https://operations.osmfoundation.org/policies/nominatim/)。地图由 Leaflet 显示 OpenStreetMap 底图。

此流程不使用 API Key、Cookie 或登录。底层百度全景接口不是官方文档提供的稳定 API。百度当前服务条款要求使用官方文档列明的功能，并限制直接抓取内部数据及下载、存储相关内容；科研或非商业用途本身不代表已获授权。仅在你已确认拥有相应授权时使用。程序按顺序限速，遇到 HTTP 拒绝、访问验证或接口结构变化会停止，不会尝试绕过。单次范围不超过 20 km × 20 km、400 km²，单次最多生成 5000 个采样点；街景缩略图预览每次最多 25 张；图像与坐标元数据由用户通过现有结果包导出。详见[百度地图开放平台服务条款](https://lbsyun.baidu.com/docs/pcsa?title=law%2Fopen%2Flaw)。

HNU v6 的完整研究采集流程还会核对道路侧、站点距离、双向不同 pano 与方向标签。当前分析系统复用了其坐标变换、pano 查询与定向图像下载底层；交互式采集仅做 100 m 最近 pano 距离限制，不等同于 HNU v6 的双向样本验证报告。

## 本机 Python 训练模式（已配置，默认不启动）

训练数据页现在包含真实训练服务状态、设备检测、训练参数、任务轮次/日志/指标展示、停止任务和 `best.pt` 下载入口。要准备训练环境，请双击 `training_service/start_training_service.command`；它会建立隔离的 Python 环境并安装依赖，服务只监听本机 `127.0.0.1:8766`。服务启动不会开始训练，也不会立即下载模型权重；仅在训练页点击“开始真实训练”并确认后，才会提交数据、载入基础权重并运行训练。

本机服务支持 YOLOv8n/s/m、轮次、尺寸、批次、自动/CPU/MPS/CUDA 设备、workers 与早停等待轮次配置。支持实时轮次、验证指标和日志查询、停止当前任务、查看本机最近训练记录与日志、下载最佳权重。训练源码和接口见 [training_service/README.md](training_service/README.md)。当前仅完成页面与训练服务配置，没有启动训练或安装训练依赖。

## 模型与训练说明

内置模型通过 Hugging Face Hub 的 Transformers.js 兼容权重推理。预训练类别来自 COCO，未针对特定街景数据完成微调。

自定义模型当前接收标准 YOLOv8 检测头 ONNX，输入为 RGB、归一化张量及方形 letterbox，输出为 `[1, 4+类别数, 候选数]` 或转置形式（也兼容带 objectness 通道的常见输出）。其他网络结构、预处理或 NMS 导出方式可能需要适配器。

“训练数据”页面根据一键确认的批量预标注结果生成 YOLO 数据集；如需调整检测框，也可在单图工作台人工校正，也可连接本机 Python 服务运行 Ultralytics 训练。训练需用户在页面主动确认启动。内置权重是通用预训练模型，不代表已在特定街景数据上验证；目标数量提示是简单规则统计，不构成交通安全判断。
